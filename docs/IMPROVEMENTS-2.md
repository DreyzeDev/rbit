## 1. Агентное ядро

- [ ] **Тест-гейт.** Расширить self-check: если в воркспейсе есть тесты
      (`pytest`/`npm test`/`cargo test`) и ход менял код — прогнать их до
      финального ответа; при падении — один круг фикса. Конфиг `test_gate`.
- [ ] **Предиктивная компакция.** Перед отправкой считать токены запроса
      (`tiktoken`); при 90% контекста — компакция до запроса, а не после 400.
- [ ] **Фоновые субагенты.** `subagent(goal, background=true)` — воркер живёт
      параллельно, результат приходит карточкой; `Esc` не убивает фоновых.
- [ ] **Второе мнение.** `/second-opinion` — тот же промпт в другую модель
      (из `model_routing.heavy`), ответы рядом.
- [ ] **Кэш истории.** `cache_control` не только на system, но и на稳定ную
      часть истории (последний tool-юнит перед хвостом).
- [ ] **Стриминг tool-аргументов в карточке** (не только в статусе):
      карточка инструмента появляется сразу с растущими аргументами.
- [ ] **Авто-масштаб параллелизма**: `MAX_PARALLEL_TOOLS` из конфига и по
      типу инструментов (read — 8, webfetch — 2).

## 2. Инструменты

- [ ] **`list_changes`** — сводка правок текущей сессии для агента
      (файлы, +/-, дифф последнего шага).
- [ ] **`websearch`** — поиск через DuckDuckGo HTML или Brave API
      (опциональный ключ), отдача топ-8 результатов.
- [ ] **`schedule`** — отложенные команды (`schedule 30m "run tests"`).
- [ ] **`notebook` — экспорт ячейки в `.py`** для обычного линта.
- [ ] **`bash` — pty-режим** для интерактивных команд (progress bars не ломаются).

## 3. TUI и Desktop

- [ ] **Resize сайдбара драгом**, ширина в конфиге.
- [ ] **Миниатюры картинок** в ленте для vision-аттачей (halfblocks).
- [ ] **Скиллы в палитре**: `/skill` показывает установленные скиллы
      с описаниями; хоткей — быстрый вызов последнего.
- [ ] **Копирование код-блока по хоткею** внутри карточки ответа.
- [ ] **Desktop: авто-обновление** через electron-updater + GitHub Releases.
- [ ] **Desktop: трей и глобальный хоткей** «показать rbit».
- [ ] **Desktop: единый рендер** — Electron грузит URL serve (один источник UI).

## 4. CLI и автоматизация

- [ ] **`rbit config get/set`** — управление конфигом без ручного JSON.
- [ ] **`rbit sessions --export-all --format html`** — массовый экспорт.
- [ ] **`rbit mcp`** — каркас MCP-клиента: `list`, `call <server> <tool>`.
- [ ] **`rbit bench --report md`** — бенчмарк с выгрузкой таблицы в файл.

## 5. Хранение и память

- [ ] **Авто-память**: после хода LLM-выжимка фактов (стек, команды, пути)
      с дедупликацией в `.rbit/memory.md`.
- [ ] **Семантический поиск по сессиям** — локальные embeddings
      (sentence-transformers, опционально) поверх `/search`.
- [ ] **`/continue <session>`** — вплести выжимку другой сессии в контекст.

## 6. Инфраструктура

- [ ] **Lazy imports** — ускорить холодный старт `rbit` (<300ms).
- [ ] **`--strict-lint` в CI** — прогон полного ruff-набора на rbit/ с базлайном.
- [ ] **Интеграционные тесты serve** — curl-цикл против запущенного сервера.
