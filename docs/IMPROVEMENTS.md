# rbit — бэклог улучшений

Отобранный и приоритизированный список идей. Всё оформлено так, чтобы можно было брать
пункт и делать без дополнительного исследования: указано «зачем», «где» и «как».

**Легенда**

| Метка | Значение |
|---|---|
| `P0` | Делать первым: сильно повышает ценность или закрывает реальную боль |
| `P1` | Важно: заметно улучшает продукт, но не блокирует |
| `P2` | Полировка и расширение |
| `S` / `M` / `L` | Оценка размера: до полудня / до пары дней / неделя+ |

Отметка `[ ]` — сделано `[x]`.

## 1. Агентное ядро

- [ ] **Параллельные tool calls.** Сейчас инструменты вызываются строго по одному
      (`for tc in tool_calls` в `_run_openai_compatible`). Для независимых read-only
      вызовов собирать корутины и запускать через `asyncio.gather`, карточки монтировать
      по мере завершения. Ограничить `asyncio.Semaphore(4)`.
      *Где:* `rbit/agent.py` → `_run_openai_compatible`.
- [ ] **Планировщик хода.** Перед первым tool call просить модель 1–3 строки плана и
      показывать его в статусной строке — меньше «слепых» правок на больших задачах.
- [ ] **Бюджет шагов и стоимости.** Считать `tokens * cost_per_1k` по каждому шагу,
      останавливаться при превышении лимита из конфига (`max_cost_usd`, `max_steps`).
- [ ] **Суб-агент `explore`.** Инструмент `subagent(goal, agent="explore")`, который
      делает отдельный короткий цикл с урезанным набором read-only инструментов и
      возвращает выжимку. Отдельная карточка `▸ Subagent` в ленте.
- [ ] **Профили системного промпта.** `--profile fast|careful|reviewer|docs`:
      разные акценты и разные разрешённые инструменты.
- [ ] **Само-проверка ответа.** После генерации — прогон `lint`/`tests` по затронутым
      файлам и авто-доправка (максимум один круг), чтобы не требовать этого от человека.
- [ ] **Кэш промптов.** Для провайдеров с prompt caching (Anthropic/OpenRouter)
      помечать стабильную часть системного промпта и истории.
- [ ] **Стриминг tool-аргументов в UI.** Сейчас карточка ждёт завершения аргументов;
      показывать `write foo.py · 1.2 KB` по мере прихода.
- [ ] **Прерывание по `Esc` без потери частичного ответа.** Сохранять уже
      полученный текст как сообщение с пометкой «interrupted».
- [ ] **Fallback модели.** При 404/401 на выбранной модели автоматически откатываться
      на `rbit/smart-local` с уведомлением, а не падать с ошибкой.

## 2. Инструменты

- [ ] **`symbols`** — AST-индекс: функции, классы, методы с сигнатурами и строками.
      Питон — `ast`; JS/TS — регулярные паттерны; Markdown — заголовки.
      Экономит чтение целых файлов.
- [ ] **`diagnostics`** — `ast.parse` для `.py`, `json.loads` для `.json`,
      `tomllib` для `.toml`, `ruff` для линта. Применять автоматически после
      `write`/`edit` и дописывать результат в `tool`-сообщение.
- [ ] **Авто-чекпоинт.** Перед первым изменением в сессии создавать
      `auto: before-edit` чекпоинт (без дублей за ход).
- [ ] **Секрет-гард.** Запрет `read` на `.env`, `*.pem`, `id_rsa`, `credentials.json`;
      редача `sk-…`, `gho_…`, `xoxb-…` в выводе инструментов и в `export`.
      Настройка `allow_secret_reads` в конфиге.
- [ ] **`apply_patch`** — настоящий unified diff на входе вместо пары строк:
      удобнее для больших правок и точнее, чем `edit`.
- [ ] **`edit` с fuzzy-поиском.** Если `oldString` не найден дословно — искать с
      нормализацией пробелов и отступов, возвращать предупреждение о неточном матче.
- [ ] **`glob`/`grep` на `.gitignore`.** Уважать правила репозитория, а не только
      жёсткий `IGNORED_DIRS`.
- [ ] **`grep` с контекстом и лимитом по файлу**, а также `-l` (только имена файлов).
- [ ] **`bash` с таймаутом из аргументов** и `background=true` для долгих процессов
      (dev-сервер, тесты), с карточкой и кнопкой «остановить».
- [ ] **`webfetch` → читаемый Markdown.** Вырезать навигацию, отдавать структуру h1–h3,
      резать по бюджету токенов, кэшировать на 10 минут.
- [ ] **`todo` как единый источник правды.** Синхронизация `todowrite` ↔ модалка ↔
      сайдбар, чтобы статусы не расходились.
- [ ] **`notebook` (`.ipynb`)**: чтение ячеек и точечная правка кода без порчи JSON.
- [ ] **`git` helper-инструмент** для безопасных read-only операций (`status`, `diff`,
      `log`, `blame`) с фильтрацией по пути.

## 4. CLI и автоматизация

- [ ] **`rbit map [dir]`** — дерево проекта с размерами, языками и бюджетом токенов;
      флаги `--max-tokens`, `--json`.
- [ ] **`rbit lint [dir]`** — ruff/pyflakes одним прогоном, код возврата для CI.
- [ ] **`rbit run --stdin`** — читать задачу из pipe: `git diff | rbit run "ревью"`.
- [ ] **`rbit run --output-format jsonl`** — событийный поток (tool_call, message,
      done) для интеграций.
- [ ] **`rbit commit`** — сгенерировать сообщение по diff, `--apply` для коммита.
- [ ] **`rbit init`** — создать `RBIT.md` и `.rbit/memory.md` по анализу проекта.
- [ ] **`rbit serve`** — локальный HTTP/SSE endpoint (аналог OpenAI API) для внешних
      клиентов и собственного UI.
- [ ] **Shell completion** для bash/zsh/PowerShell (`rbit --generate-completion`).
- [ ] **`rbit update`** — проверка и установка новой версии.
- [ ] **`--quiet` / `--verbose` / `--trace`** — уровни логов для CI и отладки.
- [ ] **Конфиг-профили** (`--profile work|oss|local`) с наложением на `config.json`.
- [ ] **`rbit sessions --prune 30d`** — чистка старых сессий и чекпоинтов.

## 6. Безопасность и надёжность

- [ ] **Подтверждение для опасных bash** уже есть — добавить список deny-паттернов
      (`rm -rf /`, `format`, `git push --force`, `:(){:|:&};:`).
- [ ] **Песочница для bash**: рабочая директория по умолчанию, `--sandbox` с
      ограничением путей и сетевых вызовов (там, где доступно).
- [ ] **Редача секретов** в `export_session_markdown`, логах и tool-выводе.
- [ ] **Атомарная запись файлов** (temp + `os.replace`), чтобы падение не рвало файл.
- [ ] **Восстановление после краха**: незавершённая сессия помечается и предлагается
      к продолжению при старте.
- [ ] **Валидация путей**: запрет выхода за workspace (кроме явного `--allow-outside`).
- [ ] **Лимиты чекпоинтов**: ротация по N штук / по размеру, иначе `.rbit/` растёт.
- [ ] **Санитайз ANSI** в выводе `bash` перед показом в TUI (управляющие
      последовательности ломают рендер).
- [ ] **Права на `.rbit/config.json`** (там API-ключ): `0600` на POSIX.
- [ ] **Ключи не в конфиге, а в keyring** (`keyring` как опция), конфиг хранит ссылку.

## Анти-бэклог (сознательно не делаем)

- Собственный GUI/Electron-оболочка — противоречит идее терминального агента.
- Встроенный редактор кода — есть редакторы, TUI должен оставаться лёгким.
- Собственный векторный индекс для RAG — `grep` + `symbols` дешевле и предсказуемее.
- Автоматические коммиты без подтверждения — слишком опасно по умолчанию.
- Телеметрия по умолчанию — несовместимо с «всё локально».
